# Documentation

Documentation of the Eclipse Tractus-X **Dataspace Management** (new portal). This repository is the leading
repository of the product (TRG 2.04).

| Folder | Content | TRG |
|---|---|---|
| [architecture](architecture/README.md) | Architecture documentation following arc42: context, modules, flows, deployment, decisions | 1.05 |
| [admin](admin/README.md) | Administrator guide: installation, configuration, secrets, operation, upgrade | 1.06 |
| [api](api/README.md) | Interface documentation: OpenAPI per module and of the installation | 1.08 |
| [User manual](https://github.com/eclipse-tractusx/dataspace-mgm-ui/blob/main/docs/user/README.md) | End user manual, kept with the UI in `dataspace-mgm-ui` | 1.07 |

Further entry points:

- [README.md](../README.md): overview, local development, contact
- [INSTALL.md](../INSTALL.md): installation with Helm
- [Chart README](../charts/dataspace-mgm/README.md): all values of the Helm chart
- [CHANGELOG.md](../CHANGELOG.md): changes per release
- [Hackathon scaffold](developers/hackathon-scaffold.md): developer guide of the scaffold (modules, call convention, test data, demo)
- [AGENTS.md](../AGENTS.md): rules for coding agents and the people who use them
